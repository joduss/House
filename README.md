# At home · 360° tour

Static panorama viewer for GitHub Pages. Includes only the 11 images from the **Best** scene.

Site: https://joduss.github.io/House/

To preview, run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

The scene list is in `scenes.json`; no backend or build step is required. Pannellum is bundled under `vendor/` with its license.

Publish from the `main` branch, repository root, using GitHub Pages.
